# Compute Cross Distances

Computes the cross distances between two sets of indices in matrix `X`.

## Usage

``` r
.compute_cross_dists(X, inds_a, inds_b, distance)
```

## Arguments

- X:

  Numeric matrix of samples.

- inds_a:

  Integer vector of indices for the first set.

- inds_b:

  Integer vector of indices for the second set.

- distance:

  String specifying the distance metric.

## Value

Numeric matrix of cross distances.
