# Calculate PAS score

PAS score measures the clustering performance by calculating the
randomness of the spots that located outside of the spatial region where
it was clustered to. Lower PAS score indicates better spatial domian
clustering performance.

## Usage

``` r
PAS(labels, location, k = 10, ...)
```

## Arguments

- labels:

  Cluster labels.

- location:

  A numerical matrix containing the location information, with rows as
  samples and columns as location dimensions.

- k:

  Number of nearest neighbors.

- ...:

  Optional params for
  [`findSpatialKNN()`](https://roseyuan.github.io/poem/reference/findSpatialKNN.md).

## Value

A numeric value for PAS score, and a boolean vector about the abnormal
spots.
