# Get Sub matrix

Extract a sub matrix from a matrix based on optional row and column
indices.

## Usage

``` r
.get_submatrix(arr, inds_a = NULL, inds_b = NULL)
```

## Arguments

- arr:

  Numeric matrix.

- inds_a:

  Optional integer vector for row indices.

- inds_b:

  Optional integer vector for column indices.

## Value

Numeric matrix representing the sub matrix.
